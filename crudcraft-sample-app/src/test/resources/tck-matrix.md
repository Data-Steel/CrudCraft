# CrudCraft Sample-App TCK Matrix

Every row is a compatibility promise for generated CrudCraft code in a real Spring Boot
application. The `id` column must appear as a method-level JUnit `@Tag` on at least one
sample-app Testcontainers test. The `evidence` column names the concrete `Class#method` test.
The build writes the resolved coverage report to `target/tck-coverage.md` and fails when any row loses its test evidence.
