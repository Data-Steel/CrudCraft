# CrudCraft Documentation

CrudCraft documentation helps developers generate Spring Boot CRUD APIs and understand the codegen/runtime features without guessing.

Use this page to choose the right documentation area.

## Documentation Areas

| Area | Purpose | Primary reader |
|---|---|---|
| [Quick Start](quick-start/) | Get a working generated API quickly. | First-time users |
| [Feature Guides](feature-guides/) | Learn every user-facing CrudCraft feature with practical examples and exact behavior. | Application developers |
| [Architecture](architecture/) | Understand codegen, runtime, contracts, module boundaries, and design decisions. | Contributors and evaluators |
| [Contributor Handbook](contributor-handbook/) | Change the repository correctly. | Contributors |
| [Maintainer Handbook](maintainer-handbook/) | Govern releases, compatibility, quality, and incidents. | Maintainers |
| [Feature Coverage](features.md) | Audit which code-derived features are documented. | Contributors and maintainers |

Feature Guides are the only feature documentation column. Exact feature facts live there; contributor, maintainer, and upgrade policy live in their own handbook pages.
